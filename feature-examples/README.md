# Feature examples

One Tesseract mechanism each, shown on its own: a custom WGSL shader, a track matte, a text animator, a gain envelope, a procedural expression. Small and deliberately uncluttered — the point is to see how the feature is wired, without a production around it.

Typical shape: one scene, one to four layers, two to six seconds.
